找到了吗Did you find it?

每个穴位页上「找到了吗」的回答，和「我也感觉到了」一样：只记每个穴位被点了几次「找到了」、几次「没找到」，不记名字，不记 IP，不用 cookie。我们用它来改写那几句「用手怎么找」。Answers to “Did you find it?” on each point page work like “Me too”: only how many times each point got “Yes” or “No”. No names, no IP addresses, no cookies. We use the counts to rewrite the directions.

我也感觉到了Me too

只记每一处被点了几次。不记名字，不记 IP，不用 cookie。你的浏览器会在本机记住你点过，免得重复计数；清除浏览器数据，它就忘了。计数由 Cloudflare 运行。Only the number of taps on each item is kept. No names, no IP addresses, no cookies. Your own browser remembers that you tapped, so you aren't counted twice; clearing your browser data forgets it. The counter runs on Cloudflare.

林子The Forest

在林子里点「感觉到了 · 没感觉 · 说不清」时，只给「这个体式、这个地方、这个回答」记一次数，用的是和「我也感觉到了」同一个计数器。不记名字，不记 IP，不用 cookie。同一个浏览器同一天对同一个回答只算一次，靠的是你的浏览器在本机记住；清除浏览器数据，它就忘了。When you tap "Yes, No or Not sure" in the Forest, only one count is added for that pose, that place and that answer, on the same counter as "Me too". No names, no IP addresses, no cookies. The same answer counts once per browser per day; your own browser remembers that locally, and clearing your browser data forgets it.

叶子Leaves

回答「找到了吗」以后，你可以接住一片飘过来的叶子（比如「热了」「卡在这一步」）。这和「我也感觉到了」一样，只给那片叶子记一次数：不记名字，不记 IP，不用 cookie；你的浏览器在本机记住你接过哪片，清除浏览器数据，它就忘了。After answering "Did you find it?", you can catch a drifting leaf (such as "warm" or "one step is unclear"). Like "Me too", this only adds one to that leaf's count: no names, no IP addresses, no cookies. Your own browser remembers which leaves you caught; clearing your browser data forgets it.
