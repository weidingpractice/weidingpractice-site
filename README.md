# weidingpractice-site

Wei Ding · Practice Notes — the public website for weidingpractice.com.

These files are generated from Practice Notes (Wei's private practice log).

## Publishing principle

Open by default. Everything in Practice Notes goes public unless it carries a legal risk:

- **Copyright:** quote other people briefly and by name; never reproduce long passages or class transcripts.
- **Privacy:** never publish other students' words or details.
- **Health claims:** write about where attention goes, never about what something treats.
- **Trademarks:** no third-party characters or logos.

The content is classical texts and Wei's own practice. Contemporary teachers are inputs; what Wei has tested in her own body and written in her own words is her own. Unchecked sources go up marked "to be checked"; principles still being tested go up marked "still testing". The private practice log itself stays private. Changes arrive as pull requests for Wei to review; merging into `main` publishes the site through Porkbun Static Hosting.

- `index.html` — the point index, grouped by where each point sits on the body
- one page per point (`laogong.html`, `yongquan.html`, …): how to find it by hand, the poses that use it, its channel and classical source
- `poses.html` and one page per pose (`downward-dog.html`, `saddle.html`)
- `principles.html` — working principles
- `404.html`, `robots.txt`, `sitemap.xml`, `style.css`
